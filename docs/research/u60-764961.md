# U60 764961: a fixes hotfix of 764025

Build 764961 replaced 764025 on `public` on 2026-11-26 (oni-archives tag `U60-764961`, branch
`release`; Windows main depot manifest 5153386320445224495, Linux 2228414795151513219). Klei's
notes list about twenty fixes, art and UI changes, and a Windows build signed by Microsoft. The
Unity version is still 6000.3.17f1.

- **Changed:** `Assembly-CSharp.dll` (75 members), the serialized data (`globalgamemanagers`,
  `resources.assets`, `sharedassets0.assets` and its `.resS`, `sharedassets2.assets`,
  `boot.config`, `hashes.json`), three DLC bundles (`cosmetic2_bundle`, `dlc3_bundle`,
  `dlc5_bundle`), the Korean strings and the strings template. Three DLC depots changed with them
  (3302471/3, 4310081/3, 5315881/3).
- **Windows only:** every one of its 57 native and managed binaries now carries an Authenticode
  signature (15,696 bytes appended; the PE header's checksum and certificate entry changed, every
  other byte the same), so each has a new hash. SimDLL is also rebuilt, with no code change: its
  build stamps and the changelist.
- **Unchanged:** firstpass and every other managed library (AssemblyDiff, and their bytes on
  Linux), FMOD (`libfmodstudio.so` the same bytes; `fmodstudio.dll` the same bytes but for the
  signature), the banks, `level0`, `sharedassets1.assets` and the other bundles. On Linux every
  file but the ones above is 764025's, `libSimDLL.so` included.

Sources:
- oni-archives: `changed U60-764025 U60-764961` (`py tools\archive.py`; the MCP server did not
  see the new tag yet) and `archive.py diff` of each changed member. Citations are member keys at

- MD5 of every file of `E:\oni-builds\oni-win-764025` against `oni-win-764961` (1,639 files

- UnityPy listings of `globalgamemanagers`, `level0`, `resources.assets` and

## Summary

- **One tweak's bodies changed.** 764961 ships the released-sounds fix sent to Klei
  (`fix-released-sounds`, docs/TWEAKS.md). Its two replaced bodies have new hashes; reviewed and
  accepted, so the tweak still replaces them and Moono plays as before. Every other fingerprinted
  body is 764025's. With the new hashes 53 of 53 tweaks pass and install on both builds.
- **fmod-steal-fix** needed a new row: 764961's `fmodstudio.dll` is 764025's file with a
  signature appended. Its mapped sections are the same bytes, so the same patch applies, listed
  by the new SHA-256. Without it the fix would be off on Windows.
- **Public API:** two members gone (`GameUtil.ClearCell(int, bool)` now returns `bool`, and
  `Navigator.OnForcedCleanUp` is gone), eight added. A mod calling the first or patching the
  second breaks on 764961, in the original too.
- **Version check:** the Unity version is unchanged, so the current release starts on 764961.

## Game tweaks

`check-tweaks --review` on `linux-764961` and `win-764961` before the new fingerprints: 52 of 53
tweaks passed, `fix-released-sounds` off on two changed bodies:

- `AmbienceManager.Layer.Stop` (7345132928a8ba90): the game now clears the handle after
  `release()`. The tweak's replacement is the same code.
- `LoopingSoundManager.StopAllSounds` (f2019ddecea6fd01): the game now takes each playing loop
  off the parameter updaters (`RemoveFromParameterUpdaters`), clears its handle and clears its
  PLAYING flag. The tweak's replacement does all but the last: the loop stays flagged as playing,
  and the game stops it a frame later as it leaves the view (docs/TWEAKS.md, "The released sounds
  fix", says why).

Both hashes are accepted for `linux-764961` and `win-764961`, so on 764961 the tweak still
replaces both methods and Moono's behaviour does not change. With the game fixed, the tweak now
only keeps the playing flag; whether to leave it out on 764961 instead is open (below). Every
other list that names 764025 names both 764961 builds with the same hash. The lookup not
checked, `ProbeRepair`'s enumeration of `Grid.SuitMarker`'s fields, is as on 764025.

Changed types the source names, checked against their tweaks: `AmbienceManager` and
`LoopingSoundManager` (above); `Navigator` (above, `path-probe-repair`); `KleiInventoryScreen`
(the Moono Tweaks screen's search box); `SelectToolHoverTextCard` (the host's guard for mods'
patches); `KCrashReporter` (a comment in `MonoDllNotFound` on `IsOperatingSystemBlockedError`,
unchanged); `GameUtil` (a comment in the keyboard layout code on `GetKeycodeLocalized`,
unchanged); `KMod.Mod::GetMostSuitableArchive` (`ModInfo`'s mirror of its choice: only the
inlined build number changed, and `ModInfo` reads the installed game's).

**fmod-steal-fix.** It patches only a library whose SHA-256 it lists. 764961's `fmodstudio.dll`
has a new hash only from its signature: the same patch site, checks, cave and counter bytes, so
it is listed as a second row with the same patch (`FmodStealPatch.Known`), and the shipped-files
test finds a library by its hash. FMOD is still 2.03.12 build 160365. `libfmodstudio.so` is
764025's file.
