# U60 764025: a hotfix of 763796

Build 764025 replaced 763796 on `public` on 2026-11-19 (oni-archives tag `U60-764025`, branch
`release`; Windows main depot manifest 5276965693570050331, Linux 1892959096482746364). The
Unity version is still 6000.3.17f1. Moono's retarget to it is housekeeping: nothing Moono patches
changed, so the fingerprints were re-stamped and the build retargeted, with no QA runs.

- **Changed:** `Assembly-CSharp.dll`, SimDLL (rebuilt, no code change), and the serialized data
  (`globalgamemanagers`, `level0`, `resources.assets`, `sharedassets*`, `boot.config`,
  `hashes.json`). On Linux, every other file is 763796's bytes, `libSimDLL.so` included.
- **Unchanged:** firstpass and every other managed library (the reference assemblies differ
  only in Assembly-CSharp), FMOD (fmod-steal-fix's known files), the banks and the bundles.

Sources: `changed U60-763796 U60-764025` in oni-archives (the MCP server's `changed_members`
still fails with "too many values to unpack"); MD5 of every file of
`E:\oni-builds\oni-linux-763796` and `oni-linux-764025` (`.DepotDownloader` left out);
check-tweaks on every frozen build.
